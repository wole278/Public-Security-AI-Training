### 模板 1：恶劣天气 / 节假日大客流交通排堵与治安安保预案
```markdown
【角色】你是上海市某区公安分局情指中心与交警支队联勤指挥长。
【背景与约束】本辖区将于 [明日早高峰 06:30-09:30 / 本周五晚 18:00-23:00] 迎来 [暴雨橙色预警 / 某商圈万人演唱会散场]。辖区关键节点包括：[3处易积水下立交 / 2个地铁换乘口 / 1条双向4车道主干道]。要求：杜绝空话，措施精确到时段、卡点与联动部门。
【任务】请制定一份《分级响应与交通排堵治安防控指令单》。
【输出格式】请输出 3 张 Markdown 表格：
1. 《前端岗点布警与联勤装备清单》（含交警、派出所、市政/地铁物业联动）；
2. 《三级预警熔断阈值与分流绕行管控表》（按积水深度或客流密度明确“何时封控、往哪分流、可变情报板显示话术”）；
3. 《突发抛锚/拥堵死锁/人员推搡 5分钟快处SOP》。
```
