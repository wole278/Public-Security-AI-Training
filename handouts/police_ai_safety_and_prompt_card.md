# 公安干警 AI 安全脱敏口诀与四步提问桌垫卡（可打印派发）

> **使用说明**：建议双面打印塑封，放置于办公桌或电脑旁。外网使用大模型前必看正面【安全脱敏铁律】，提问前套用背面【R-C-T-F 万能公式】。

---

## 🛡️ 正面：警务 AI 安全合规“三不准、两神技、三核查”

### 一、 严守“三不准”死线（L0 涉密红线）
1. **不准一机两用**：公安网（内网）、视频专网数据**严禁**直接复制粘贴至互联网公有大模型网页或小程序。
2. **不准上传 P3 级敏感要素**：外网提问中**绝不能出现**真实姓名、18位身份证号、真实手机号、银行卡号、真实车牌号、具体门牌室号、未公开在侦案件编号及专网 IP。
3. **不准盲信盲引**：AI 生成的法条引用、案情推演、数据结论，未经主办民警人工核对原卷与法规，**严禁直接入卷或作为执法依据**。

### 二、 外网借力“两神技”（真数据不出网，白嫖 AI 算力）

| 技法 | 适用场景 | 1分钟标准操作口诀 |
| :--- | :--- | :--- |
| **神技 1：留壳去肉脱敏法** | 写安保预案、理讯问笔录、改协查通报、写周报总结 | **真名换代号**（`张某甲/李某乙`），**尾号打星号**（`尾号8801卡`），**地名缩片区**（`某商业街/A小区`），只把**事件逻辑壳**发给 AI，生成后再本地替换回真名。 |
| **神技 2：表头脱敏代写法** | 洗银行流水、筛通话详单、算卡口流量、掘 110 警情 | **真表绝不出网！只复制 Excel 第 1 行表头字段名 + 2 行自己编的假数据**发给 AI，让它写离线 Python/SQL/VBA 脚本，拿回脚本在内网电脑 3 秒跑完 10 万条真数据！ |

## 🎯 背面：警务提示词【R-C-T-F 四步万能公式】

告别“帮我写个方案”的菜鸟提问，每次提问按以下 4 行填空，AI 立刻变身十年老科长/资深工程师：

```markdown
【R 角色设定】你是一名拥有10年经验的上海公安 [交警中队长 / 刑侦预审专家 / 科信Python工程师 / 法制审核员]。
【C 背景与约束】当前面临 [具体痛点/路网环境/案件背景]。严格遵守：1. 严禁编造未提供的事实；2. 措施必须精确到岗位、时段、动作，去官话套话；3. [内网零依赖Python标准库 / 符合公安公文规范]。
【T 核心任务与脱敏数据】请基于下方提供的 [脱敏笔录 / Excel表头结构 / 辖区警情统计]，完成：[1. 矛盾排查；2. 管控措施；3. 编写自动化脚本]。
【F 输出格式】请严格使用 [Markdown 表格（列名为：...） / 标准JSON / 零依赖Python代码] 格式输出。
```

### ⚡ 四个救命追问句式（当 AI 第一次回答不够好时直接发）：
1. **嫌它太啰嗦官腔**：*“请删掉所有‘提高认识、加强领导’等空话套话，所有措施必须写出：**谁（警种/联动部门）、在几点几分、什么具体位置、用什么物理手段或动作干什么**！”*
2. **怕它胡编乱造（幻觉）**：*“请逐条核对你的回答，凡是原文中没有明确提及的时间、金额和细节，一律标注为【待侦查核实】，严禁自行脑补！”*
3. **代码在内网报错**：*“我的公安内网电脑没有联网，无法 `pip install pandas/openpyxl`，请将上述代码改写为**仅使用 Python 3 内置标准库（csv/json/collections/datetime）**的零依赖版本！”*
4. **想让它挑刺防退查**：*“现在请切换为检察院批捕科检察官视角，对上述案情和在卷证据进行挑刺，列出最容易导致‘存疑不捕’或‘退回补充侦查’的 3 个客观证据缺口。”*
